# Flavors of DC workflow — what changed

**Source:** `CopyofFlavorsofDCWorkflow.html` (In-Person Flavors of DC Event Workflow, updated September 2026)

**CRM:** Family B template seed in `experienceWorkflowSeed.ts` / `experienceMatrix.ts` (re-seeded as **72** task defs). Existing events keep old tasks until **Regenerate Event Workflow**.

## Summary

Flavors is no longer a thin overlay on walking-tour tasks. It has its own checklist aligned to the Sept 2026 playbook.

## Notable changes

- **Upon deposit:** Secure Event Team Lead immediately; early participant list + FareHarbor embed; custom add-ons (glassware, cheeseboard, olive oil, eatery kits).
- **ROS:** Confirm menu / eateries (not “tour itinerary”); opening-talk preference; wheelchair; Alberto / DC Nation transport; FoDC add-on progress.
- **Two weeks:** Eatery ordering procedures + pickup/delivery plan (~1h before start); headcount; ticketed beverage count; transport remind/driver; FoDC inventory order + BEO inventory double-check.
- **One week / 72–48h / 24h:** Print BEO for Event Team Lead; Guide & Support phone check-in; 72h reconfirm eatery reservations; acquire ice.
- **During:** FOH presentation (trays, utensils, salad oil ratio, posters); Event Lead with day-of POC + photos.
- **Post:** Consumption invoice (if alcohol); EVENT REPORT (labor / venue / supplies).

## Removed for Flavors only

- Walking-tour **~45 min between stops**, dine-around / tour kit.
- Shared Family B **aprons** task and generic **1-week inventory order** (FoDC inventory is at ~2 weeks instead).
- Shared **Host/Instructor** 72–48h check-in (replaced by Guide & Support wording).
