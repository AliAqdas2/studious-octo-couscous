## Notable changes

- **3 weeks:** Check office inventory; order kit supplies with per-kit quantities (container, 2″ succulents, soil 9.6 oz, rocks 14.4 oz, sand 7.4 oz, moss 0.4 oz, spray bottles, bags, charcoal 2.4 oz, decorative ducks, logo apron, chopsticks/utensils).

- **1 week:** Print marketing + BEO with supplies; pick up logo’d add-ons.
- **24h:** Triple-check inventory; acquire ice.
- **Post:** Consumption invoice (if alcohol); EVENT REPORT.
